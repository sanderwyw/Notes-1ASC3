- LEFT/RIGHT OUTER JOIN
	- Use cases
		- (1-N) relationships where minimum cardinality of A is 0 (can exist without taking part in relationship)
			- There may be cases of A that do not have a match with B that should still be included (these rows will have NULL in their id column)
		- Example
			- (1-N) relationship "student is at campus"
			- Minimum cardinality of student is 0 (can exist without taking part in the relationship)
				- There may be students who are not yet linked to a campus
				- In other words: those students have NULL in the "campus_id" column
	- INNER JOIN
		- No match if there is NULL in the product
		- Commutativity
			- A INNER JOIN B = B INNER JOIN A
	- LEFT OUTER JOIN (**A**, B)
		- Steps
			-  Performs INNER JOIN
			- For every row from **tableA** that satisfies the join condition with no row from **tableB**, an extra row is added
				- In that row the columns from **tableA** get the value NULL
			- Resulting table always contains at least one row for every row of **tableA**
		- RIGHT OUTER JOIN functions similarly to LEFT OUTER JOIN, be it that **tableA** and **tableB** switch places
		- Commutativity
			- A RIGHT OUTER JOIN B != B RIGHT OUTER JOIN A
	- FULL OUTER JOIN
		- Steps
			- Performs INNER JOIN
			- For every row from tableA that satisfies the join condition with no row from tableB, an extra row is added
				- In that row the columns from tableA get the value NULL
			- For every row from tableB that satisfies the join condition with no row from tableA, an extra row is added
				- In that row the columns from tableB get the value NULL
- Joining several tables
	- Associativity of joins
		- INNER JOIN: commutative, order does not matter
		- Other JOINS: not commutative, order does matter
	- Example query
		- SELECT *
		- FROM ingredient.ingredient I
		- FULL OUTER JOIN ingredient.unit U ON I.unit_id = U.id
		- FULL OUTER JOIN ingredient.recipe R ON I.id = R.ingredient_id
	- Steps Example Query
		- Step 1 - First 2 tables are joined
			- SELECT *
			- FROM ingredient.ingredient I
			- **FULL OUTER JOIN ingredient.unit U ON I.unit_id = U.id**
		- Step 2 - Next table is joined with result
			- SELECT *
			  FROM ingredient I **FULL OUTER JOIN unit U ON I.unit_id = U.id**
			- FULL OUTER JOIN recipe R ON I.id = R.ingredient_id;
