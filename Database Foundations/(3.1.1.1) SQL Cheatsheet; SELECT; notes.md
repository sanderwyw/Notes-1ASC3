- SELECT
	- Function
		- *Requests* something from the database server
		- Most commonly used to select *columns* stored in the database server
	- Syntax
		- SELECT *column1*, *column2*
	- Details
- AS
	- Function
		- Changes the *header* for a displayed column
	- Syntax
		- *column* AS *name of choice*
	- Details
		- If the *name of choice* is a string with spaces in between, "" is required
- Creating new columns
	- If you put a string or number as a *column*, that value will be *repeated* for each row in the result
		- No header will be given
- Concatenating strings
	- Function
		- Combines multiple columns into one
	- Syntax
		- SELECT *column1* || ', ' || *column2* 
- SELECT *
	- Selects *all* columns stored within the table
- SUBSTRING
	- Function
		- Selects only a certain part of a string
	- Syntax
		- SUBSTRING(*string*, *start*, *length*)
	- Details
		- *Start* refers to the first character that will be read
		- *Length* refers to the amount of characters that will be read, starting with the character selected with *Start*
- DISTINCT
	- Function
		- Only keeps unique rows in the result
	- Syntax
		- SELECT DISTINCT *column* 
	- Details
		- Part of SELECT, not the *columns* that follow it
		- Applies DISTINCT to all column after it
		- When *two or more* columns are included that have a *different* amount of rows *after* **DISTINCT** is applied to them, *all rows* of the column with the *most rows* will be displayed, resulting in *duplicates appearing* in the *other* column(s)
- DATE
	- Function
		- A datatype that allows for the computer to do math with a date (calculating difference between days)
	- Syntax
		- Date *yyyy-mm-dd*
	- Details
		- Other time related data types:
			- Timestamp
			- Time
			- Interval
- EXTRACT FROM
	- Function
		- Allows a certain piece from a date or time to be extracted from a date (for example the month out of 2026-10-09)
	- Syntax
		- SELECT EXTRACT(*type* FROM *date*)
- CAST AS
	- Function
		- Converts a data type into another data type
	-  Syntax
		- SELECT CAST(*123* AS *integer*)
			- Converts the string '123' into the number 123
		- SELECT '*123*'::*integer*
			- Same as before, but with different notation
	- Details
		- SELECT CAST(1234 AS char(6)) will result in the string '1234  '
			- Note the additional 2 spaces to make up for the 6 characters noted in char(6)
- TO_CHAR
	- Function
		- Converts a data type into a string according to a given notation method
	- Syntax
		- SELECT TO_CHAR(*column*, *notation method*)
		- SELECT TO_CHAR(*date '1999-12-31*, dd/mm/yyyy)
			- Results in *31-12-1999*
