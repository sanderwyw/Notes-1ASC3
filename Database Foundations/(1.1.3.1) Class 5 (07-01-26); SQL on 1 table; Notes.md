- SQL Commands
	- ORDER BY
		- Function
			- Orders the results form SELECT FROM either in ascending or descending order
		- Syntax
			- SELECT *column1*, *column2* FROM *table_name* ORDER BY *column1* ASC|DESC;
		- Details
			- ASC for ascending (default)
			- DESC for descending
	- GROUP BY
		- Function
			- Groups rows that have the same values into *summary rows*
		- Syntax
			- SELECT *column1* FROM *table_name* WHERE *condition* GROUP BY *column2*

	- FROM
		- What table are we querying
	- WHERE
		- Selects certain rows based on a condition
	- SUBSTRING
		- Function
			- Selects only a certain part of a string
		- Syntax
			- SUBSTRING(*string*, *start*, *length*)
		- Details
			- *Start* refers to the first character that will be read
			- *Length* refers to the amount of characters that will be read, starting with the character selected with *Start*
	- LIKE
		- Compares with wildcards
		- % = any number of characters
		- _ = one character
		- Ex.
			- %Straat
			- %Straat%
			- Straat%
	- ILIKE
		- Just LIKE but case insensitive
	- FETCH
		- EX
			- FETCH FIRST 3 ROWS WITH TIES OFFSET 3;
				- Selects first 3 rows (including multiple for entries with same value) (skipping 2 entries each entry)
	- SELECT TOP
	- LIMIT

	- COUNT
		- Counts how many entries of a row exist
	- CASTING
		- Changes data type temporarily
		- Ex.
			- ::Integer
