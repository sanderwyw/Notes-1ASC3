- GROUP BY
	- Function
		- Groups multiple *rows* into one *box* or *summary row*
	- Syntax
		- SELECT **AGGREGATE FUNCTION**
		- **GROUP BY** *column*
	- Details
		- This function is almost always used in conjunction with *aggregate functions*, else the output result in an error
		- You can group not only on a *column*, but also on a *calculated column/ expression*
			- Ex.: **GROUP BY** **EXTRACT**(*year* **FROM** *date*)
		- You can also group on *multiple* columns at at the *same time*. This creates groups of every existing *combination* of the *rows* of the *columns* mentioned. 
- COUNT
	- Function
		- Selects the amount of *rows* in a *box*
	- Syntax
		- SELECT *column1*, **COUNT**(*column2*)
	- Details
		-  If unspecified (**SELECT COUNT( * )**) then the output will be the number of rows in the *entire* table
		- If specified (**SELECT COUNT( * )** and **GROUP BY *column***) then the output will vary for each row, representing the amount of rows in each *box* created by **GROUP BY**
- SUM
	- Function
		- *Combines* the values of various *integers* in *rows* in a *box*
	- Syntax
		- SELECT *column1*, **SUM**(*column2*)
	- Details
		- Is often confused with COUNT() but works completely differently
- MIN(), MAX(), AVG()
	- Function
		- Calculates the minimum, maximum or average of various *integers* of the *rows* inside of a *box*
	- Syntax
		- SELECT *column1*, **MIN**(*column2*)
		- SELECT *column1*, **MAX**(*column2*)
		- SELECT *column1*, **AVG**(*column2*)

- HAVING
	- Function
		- Decided which *boxes* may remain and which should *disappear* from the *result*
	- Syntax
		- **HAVING** *condition*
	- Details
		- Similar to the **WHERE** clause
			- The **WHERE** clause determines which *rows* may remain and which should disappear
			- The **HAVING** clause determines which *boxes* may remain and which should disappear
		- **HAVING** is only executed *after* the *boxes* are created
			- This means that **WHERE** (which is executed *after* **FROM**) is executed *before* **HAVING**
