- WHERE
	- Function
		- When **FROM** is executed, the *entire* table is loaded into working memory. 
		- **WHERE** then *discards* all rows that *do not* fulfil its *condition*. 
		- Afterwards **SELECT** is executed and determines which rows should be included in the output
	- Syntax
		- WHERE *condition*
	- Details
- Standard Comparison Operators
	- Function
		- Allows comparison between numbers, strings, dates and timestamps
	- Syntax
		- *row* **=** *value* (equal to)
		- *row* **!=** *value* (not equal to) 
		- *row* **>**/**<** *value* (greater than/ less than)
		- *row* **>=/<=** *value* (greater or equal to/ less or equal to)
	- Details
		- *Dates* that are farther in the past are *smaller* than a later date
		- Determining which *string* is *larger* depends on the *database*
			- We use PostgreSQL and will be used for examples
			- 'a' < 'A'
				- Lowercase letters come before uppercase letters and are thus smaller
			- 'magic' < 'monkey'
				- 'm' is the same for both letters so the next letter is compared
				- 'a' comes before 'o' in the alphabet and is thus smaller
			- 'cent' > 'century'
				- The first four letters of 'cent' are the same as 'century' but 'cent' is shorter than 'century' and is thus smaller
- IS (NOT) NULL
	- Function
		- NULL values cannot be compared with using =
		- Instead, a special comparison IS NOT or IS NOT NULL must be used
	- Syntax
		- WHERE *column* IS NULL
		- WHERE *column* IS NOT NULL
- LIKE
	- Function
		- For strings only
		- Works similar to a = operator, but adds wildcards
	- Syntax
		- WHERE *string* LIKE **%** 
		- WHERE *string* LIKE **_ 
	- Details
		- **%** represents a series of 0 or more characters
		- _ **(underscore)** represents exactly one charcter
- NOT
	- Function
		- Inverts the condition it is applied to so that if the condition is *TRUE*, *FALSE* will be returned and if the condition is *FALSE*, *TRUE* will be returned
	- Syntax
		- NOT *condition*
- AND
	- Function
		- Links multiple conditions together, returning TRUE if *both* sides of the AND statement return TRUE
	- Syntax
		- *condition* AND *condition*
- OR
	- Function
		- Links multiple conditions together, returning TRUE if *one or both* of the sides of the OR statement returns TRUE
	- Syntax
		- *condition* AND *condition*
