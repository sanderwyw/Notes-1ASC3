- CSV
	- Comma Separated Values
	- Text file that represents a table
	- Elements
		- **"Enter"** starts a new *row*
		- **","** starts a new *column*
		- Often, **";"** serves a *delimiter*, differentiating between multiple items
		- Empty cell = 2 delimiters right after each other
		- May have *header* row (contains ex. column names instead of data)
		- **""** Around data
	- Common errors
		- More or fewer columns in the CSV than in the table
		- No header in CSV, but the first row is skipped
		- Header when import expects data
		- Data type does not match
		- Set delimiter different from the one in CSV
		- Key value not unique
