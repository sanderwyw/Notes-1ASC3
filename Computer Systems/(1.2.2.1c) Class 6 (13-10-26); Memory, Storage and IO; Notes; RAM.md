- RAM
	- Cell grid
		- Example address: 011 101
			- 011 = row 3
			- 101 = column 5
		- Process
			- 1) Entire row is read
			- 2) Column is picked
			- 3) Bit is sent back to the CPU
		- Random access
			- Every cell is equally fats to reach, wherever it is
			- -> Different to a hard disk where it does vary
	- DRAM
		- Each bit within RAM is composed of a *transistor* and a *capacitor*. 
		- Bits quickly *lose* their charge, resulting in rapid *data loss*
		- Each row is rewritten/ *refreshed* thousands of time per second by the memory controller
			- This is why RAM is volatile
	- SRAM
		- RAM within the *CPU*'s cache
			- Much *faster* than DRAM
			- Keeps value as long as there is power (even without refresh)
		- Composed of a *NOT loop*
			- NOT turns 1 into 0, second NOT turns it back into 1
			- Similar to a light switch
		- Made out of *6 transistors*
			- Much more expensive than normal RAM
	- Hardware types
		- DIMM
			- Removable stick
			- Desktops and servers
			- ~13cm long
		- SO-DIMM
			- Removable stick
			- Laptops and mini-PCs
			- ~7cm long
		- Soldered
			- Chips on the motherboard
			- Thin laptops, phones
			- Not removable or upgradable
	- RAM versions
		- With newer versions, RAM becomes *faster* and require *less* electricity
		- Versions are *not* interchangeable and each need a *unique* slot
		- High speed RAM may be *bottlenecked* by the motherboard
			- DDR3
				- Since 2007
				- 800-2000 megatransfers per second
				- 1.5V
			- DDR4
				- Since 2014
				- 1600-3200 MT/s
				- 1.2V
			- DDR5
				- Since 2021
				- 4800-8800 MT/s
				- 1.1V
