- Storage Rules
	- Memory Hierarchy
		- Register 
			- Access speed = 0.3ns
			- Bytes
			- Volatile
		- Cache (L1, L2, ...)
			- KB-MB
			- Volatile
		- RAM
			- Access speed = 100ns
			- GB
			- Volatile
		- NVMe SSD
			- Access speed = 100μs
			- Speed gap of 1000x between RAM and SSD
			- TB
			- Non-volatile
		- Hard disk
			- Access speed = 10ms
			- TB
			- Non-volatile
	- Distance Limit
		- Light travels 30cm in 1 nanosecond
		- Light travels 10cm in one clock tick (0.33ns)
		- = Light, the fastest thing possible does *not* transmit *instantaneously*. This means that computers will still *lose time* when obtaining data from the RAM, SSD or HDD
