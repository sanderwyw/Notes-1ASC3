- Number Systems
	- Workings
		- Way of displaying a *value*
		- Each number represents a *part* of the *total value*
		- The *position* of a number *determines* its *value* *(positional system)*
			- A *number* is *multiplied* by the **number system's number** (10 for decimal, 2 for binary, 16 for hexadecimal) to the power of its **location**
			- Formula: *n* * **s** ^ **l**
				- *n* = number
				- **s** = number of the number system
				- **l** = location of the number
		- All number systems rely on these two rules
	- Systems
		- Decimal system
			- Each number has **10** possible states
			- Example
				- in **47**, the **4** actually represents its own value: **40**; because it takes up the *second slot* of the number
					- The **4** is multiplied by **10**^*the location of the number*
					- In this case it is in the *second* slot and is therefore multiplied by **10^1**
				- The **7** on the other hand just represents **7** because it takes up the *first slot* of the number and is therefore multiplied by **10^0** 
		- Binary system
			- Each number has **2** possible states
			- This is the *smallest* and therefore (theoretically) *simplest* number system
			- A **1** simply adds its locational value, and a **0** simply adds *nothing*
			- Example (*binary* -> *decimal*)
				- For translating the *binary number* **1010** to a *decimal number*:
				- The first **1** is located on the *fourth* slot, and thus adds *1* x **2** ^ **3** =  *8*
				- The first **0** is located on the *third* slot and thus adds *0* x **2** ^ **2** = *0*
				- If you add the rest of the values you will come to the **decimal value** *10*
			- *Decimal* -> *Binary*
				- Method 1: *largest power of 2*
					- 1) Look for the *largest power of 2* that *isn't greater* than the number you want to convert
					- 2) Write a **1** at that power's *position*
						- For example if the greatest value is 8, you'd write a 1 at 2^3
					- 3) If you *skipped* a position, write a **0** instead
					- 4) Repeat these steps until you reach 2^0
		- Octal System
			- Each number has **8** possible values (0-7)
			- The *location values* are powers of **8**
			- Not used very often
		- Hexadecimal System
			- Each number has **16** possible values (**0-9**, **A-F**)
				- **A-F** are for values **10-15**
					- A = 10
					- B = 11
					- C = 12
					- D = 13
					- E = 14
					- F = 15
			- The *location values* are powers of **8**  
			- Upper or lower case *does not matter*
			- In code you'll often see the prefix **0x** to mark a *hexadecimal* value
			- *Colours* on *websites* are written in *hex codes*
				- Such as **#FF5733** (orange-red)
				- Each *pair* of *hex digits* is the amount of *red*, *green* or *blue*
					- A value between **0** and **255** (Decimal)
					- A **00** to **FF** (Hexadecimal)
	- Conversion Techniques
		- Grouping Trick
			- For *binary* <-> *octal* <-> *hexadecimal*
				- These *numbers* can often be *divided/ split up* into groups of **8**, **4** or **3**, making conversion between them much *faster*
			- Workings
				- 1) Split up into groups
					- Split up the *original number* into at least two *groups*
					- In order to turn your *original number* into a *splittable number* you can add as many **0**s as you want at the front
				- 2) Convert groups separately
					- Convert each group of numbers as you would a *standalone number*
				- 3) Write together
					- Simply write the numbers you just obtained in the *correct order*
			- Examples
				- **10110101** -> *hexadecimal*
					- 1) Split up into groups
						- **1011** - **0101**
					- 2) Convert groups separately
						- **1011** -> **B**
						- **0101** -> **5**
					- 3) Write together
						- **B5**
				- **10110101** -> *octal*
					- 1) Split up into groups
						- **(0)10** - **110** - **101**
					- 2) Convert groups separately
						- **10** -> **2**
						- **110** -> **6**
						- **101** -> **5**
					- 3) Write together
						- **265**
