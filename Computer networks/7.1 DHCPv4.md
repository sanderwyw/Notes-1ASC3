- DHCPv4 Concepts
	- DHCPv4 Server and Client
		- Dynamic Hosts Configuration Protocol v4 *(DHCPv4)*
		- **Assigns** *IPv4 addresses* and other network configuration information **dynamically**
		- The *DHCPv4* server dynamically assigns or leases an *IPv4 address* from a **pool of addresses** for a **limited** period of time **chosen by the server** or until the client **no longer needs** the address
	- Steps to Obtain a Lease
		- When the client boots (or otherwise wants to join a network) it begins a **four-step process** to obtain a *lease*
			- 1. DHCP Discover (DHCPDISCOVER)
				- Tries to look for a router offering a lease
			- 2. DHCP Offer (DHCPOFFER)
				- Router receives the Discover and offers a IP address
			- 3. DHCP Request (DHCPREQUEST)
				- Original host receives Offers and requests to use it
			- 4. DHCP Acknowledgment (DHCPACK)
				- Router allows host to use that IP address
			- 4.2. DHCP DENIAL (DHCPNAK)
				- Router rejects host to use that IP address
	- Steps to Renew a Lease
		- Prior to *lease expiration*, the client begins a two-step process to **renew** the lease with the *DHCPv4* server
			- 1. DHCP Request (DHCPREQUEST)
				- If *DHCPREQUEST* isn't received in a given amount of time, the client broadcasts another request
			- 2. DHCP Acknowledgment (DHCPACK)
				- Server verifies and renews the lease information
	- DHCPv4 Relay
		- Enterprise servers are usually located **centrally**
		- These may provide *DHCP*, *DNS*, *TFTP* and *FTP* services for the network
		- Routers and other intermediary devices must be configured to relay DHCPv4 messages across different networks
