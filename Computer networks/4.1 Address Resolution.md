MAC and IP
- Destination on Same Network
	- There are two primary addresses assigned to a device on a LAN
		- *Layer 2* **physical** address (the MAC address)
			- Used for *NIC to NIC* communications on the *same network*
			- If a destination IP address is on the same network, the destination MAC address will be that of the destination device
		- *Layer 3* **logical** address (the IP address)
			- Used to send the packet **from** the **source device** to the **destination**
- Destination on Remote Network
	- When the *destination IP address* is on a *remote network*, the *destination MAC address* is that of the *default gateway*
		- ARP *(address resolution protocol)* is used by IPv4 to **associate** the *IPv4 address* of a device with the *MAC address* of the device *NIC*
		- *ICMPv6* is used by IPv6 to **associate** the *IPv6 address* of a device with the *MAC address* of the device *NIC*
ARP
- ARP overview
	- A device uses ARP to **determine** the *destination MAC address* of a local device when it knows its *IPv4 address*
		- So essentially IPv4 -> MAC address
	- Provides two functions 
		- Resolving IPv4 addresses to MAC addresses
		- Maintaining an ARP **table** of **IPv4 to MAC address mappings**
- ARP Functions
	- To **send** a frame, a device will search through its *ARP table* for a *destination IPv4 address* and a corresponding *MAC address*
		- If packet destination IPv4 address is on **same network**, device searches ARP table for **destination IPv4 address**
		- If destination IPv4 address is on a **different network**, devices searches ARP table for IPv4 address of the **default gateway**
		- If device locates IPv4 address, its MAC address is used as the destination MAC address in the frame
		- If **no entry** is found in the table, the device sends an ARP request
- Removing entries from ARP table
	- Entries are **not** permanent and are removed when the *ARP cache timer* expires
		- This duration varies depending on OS
	- Can also be removed manually be admin
- ARP issues
	- ARP requests are received and processed by **every** device on the local network (reduction in performance)
	- ARP replies can be spoofed by a threat actor
	- High-end switches use mitigation techniques to protect against ARP attacks
