IPv4 issues
- IPv4 is running out of addresses
	- IPv6 is 128-bit and has way more space
- IPv6 includes fixes for limitation of IPv4 as well as other enhancements
	- Issues include NAT and loT
IPv6 Address Representation
- 128 bit in length
- Written in hexadecimal
- Written as x:x:x:x:x:x:x:x with each x consisting of four hexadecimal values which are made up of 4 bits each
- A *hextet* is a segment of 16 bits or four hexadecimal values
- Omit any leading 0s
	- ONLY leading 0s not trailing 0s
	- 00ab can be shortened as ab
- Write one or multiple continuous hextets of all 0s as ::
	- Can only be used once
IPv6 Address Types
- Casting types
	- Unicast
	- Multicast
	- Anycast
		- **Unicast** address that can be **assigned** to **multiple devices**
		- A packet sent to an **anycast** address is routed to the nearest device having that address
	- There is no broadcast address
		- There is an IPv6 all-nodes **multicast** that gives the same result
- Prefix Length
	- Represented in **slash notation** and is used to indicate the **network portion** of an IPv6 address
	- Can range from 0 to 128
	- Recommended IPv6 prefix is /64 (half)
- Types of IPv6 Unicast Addresses
	- Unlike *IPv4* devices that have a **single** address, *IPv6* addresses typically half **two** unicast addresses
		- GUA *(Global Unicast Address)*
			- Similar to **public** *IPv4* address
			- Globally unique
			- Internet-routable
			- Structure
				- Global routing Prefix
					- Prefix or **network** portion of the address that is assigned by the provider
					- Varies based on *ISP* (Internet Service Provides) policies
				- Subnet ID
					- Area between the **Global Routing Prefix** and the Interface ID
					- Used by an organization to identify **subnets** within its site
				- Interface ID
					- Equivalent to *host* portion of an *IPv4* address
					- /64 subnets should be used
		- LLA *(Link-local Address)*
			- Required for **every** *IPv6-enabled* device and used to communicate with other device on the **same** local link
			- Not routable and are confined to a single link (subnet)
			- Every IPv6 network interface must have an LLA
			- LLA will be created by device if not manually configured on interface
			- IPv6 LLAs are in the fe80::/10 range
		- Unique Local Address
			- fc00::/7 to fdff::/7
			- Similar to IPv4 private addresses
			- Unique local addresses are used for **local** addressing within a site or between a **limited number of sites**
			- Can be used for devices that will never need to access another network
			- Not globally routed or translated to a global IPv6 address
- Dynamic Addressing for IPv6 GUAs
	- RS messages
		- Router solicitation
		- Sent by host devices to **discover** IPv6 routers
	- RA messages
		- Router advertisement
		- Sent by *routers* to **inform** *hosts* on how to obtain an *IPv6 GUA* 
		- Also provides useful information such as
			- Network prefix and prefix length
			- Default gateway address
			- DNS address and domain name
		- Provides three methods for *IPv6 GUA* configuration
			- SLAAC
				- Stateless address auto-configuration
				- Allows device to configure a *GUA* without the services of DHCPv6
				- Devices obtain necessary information to configure *GUA* from the ICMPv6 RA messages of the local router
				- Prefix is provided by RA and the device uses either EUI-64 or random generation method to create an interface ID
			- SLAAC with stateless DHCPv6 server
				- RA can instruct a device to use both SLAAC and stateless DHCPv6
				- The RA message suggests devices use the following
					- SLAAC to create its own IPv6 *GUA*
					- Router LLA (RA source IPv6 address) as default gateway address
					- Stateless DHCPv6 server to obtain information such as a DNS server address and a domain name
			- Stateful DHCPv6 (no SLAAC)
				- An RA can instruct a device to use stateful DHCPv6 only
				- Similar to DHCP for IPv4
				- Device can automatically receive a GUA, prefix length and the addresses of DNS servers from a stateful DHCPv6 server
				- The RA message suggests devices use the following
					- Use router LLA (RA source IPv6 address) for default gateway address
					- Stateless DHCPv6 server to obtain information such as a DNS server address and a domain name
Dynamic Addressing for IPv6 LLAs
- Dynamic LLAs
	- All IPv6 interfaces must have an IPv6 LLA
	- LLAs can be configured dynamically
	- LLA is dynamically created using the fe80::/10 prefix and the interface ID using EUI-64 process or a randomly generated 64-bit number
