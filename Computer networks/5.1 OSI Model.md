- The Rules
	- Communications Fundamentals
		- Source (sender)
		- Destination (receiver)
		- Channel (media) that provides the path of communications to occur
	- Communications Protocols
		- All communications are governed by protocols
		- **Rules** that the communications will follow
		- Rules will vary depending on protocol
		- Protocols must account for the following requirements
			- Identified sender and receiver
			- Common language and grammar
			- Speed and timing of delivery
			- Confirmation of acknowledgment requirements
	- Network Protocol Requirements
		- Common computer protocols must be in agreement and include the following requirements
			- Message encoding
			- Message formatting and encapsulation
			- Message size
			- Message timing
			- Message delivery options
	- Message encoding
		- Process of **converting** information into another **acceptable form of transmission**
		- Decoding **reverses** this process in order to interpret the information
	- Message formatting and encapsulation
		- When a message is sent it must use a specific **format** or **structure**
		- Message formats depend on the **type** of message and the **channel** that is used to deliver the message
	- Message size
		- Encoding between hosts must be in an appropriate format for the medium
			- Messages sent across the network are converted to **bits**
			- Bits are **encoded** into a pattern of light, sound or electrical impulses
			- Destination host must **decode** the signals to interpret the message
			- Messages are often split up into smaller pieces instead of being sent all at once
	- Message timing
		- Flow control
			- Manages the **rate** of data **transmittion**
			- Defines **how much** data can be sent and the speed which it can be delivered
		- Response Timeout
				- Manages **how long** a device **waits** when it does not hear a **reply** from the destination
		- Access method
			- Determines **when** someone can send a message
		- When more than one device sends traffic at the same time over the same media the message will become corrupt. This is known as a **collision**
- Protocol Suites
	- Network Protocol Suites
		- Protocol Suite
			- A **group** of inter-related **protocols** necessary to perform a communication function
			- **Sets** of **rules** that work together to help solve a problem
		- Viewed in terms of layers
			- Higher layers
			- Lower-layers- concerned with moving data and provide services to upper layers
		- Examples
			- IPS (Internet Protocol Suite) or TCP/IP
				- **Most common** protocol suite
				- Maintained by the Internet Engineering Task Force (IETF)
				- Operates at the application, transport and internet layers
				- Most common LAN protocols are ethernet and WLAN (wireless LAN)
				- Freely available to the public
				- Can be used by any vendor
				- Standards-based
				- Communication process
					- Web server encapsulating and sending a web page to a client
					- Client de-encapsulating the web page for the web browser
			- Open Systems Interconnection (OSI)
				- Lets different layers of technology talk to eachother
			- AppleTalk
				- Proprietary suite release by Apple Inc.
				- Ofc apple has their own PS istfg
			- Novell NetWare
				- Proprietary suite developed by Novell Inc.

- Reference models
	- Benefits of using a layered model
		- Can be used to explain complex concepts more simply
		- Products from different vendors can work together, which fosters competition
		- Because the layers are separate, technology or capability changes in one layer will not affect all the rest
		- Provides a common language to describe networking functions
	- OSI Reference Model
		- 7) Application
			- Contains protocols used for process-to-process communications
		- 6) Presentation
			- Provides the representation of the data transferred between application layer services
		- 5) Session
			- Provides services to the presentation layer and to manage data exchange
		- 4) Transport
			- Defines services to segment, transfer and reassemble the data for individual communications
		- 3) Network
			- Provides services to exchange the individual pieces of data over the network
		- 2) Data Link
			- Methods for exchanging data frames over a common media
		- 1) Physical
			- Describes the means to activate, maintain and de-activate physical connections

- Data Encapsulation
	- Segmenting
		- Breaking up messages into smaller units
		- Multiplexing
			- Taking multiple streams of segmented data and interweaving them together
		- Benefits
			- Increases speed
				- Large amounts of data can be sent over the network without tying up a  subnet
			- Increases efficiency
				- Only segments which fail to reach the destination need to be retransmitted instead of the entire data package
	- Sequencing
		- Sequencing messages is the process of numbering the segments so that the message may be reassembled at the destination
			- TCP (transmission control protocol) is responsible for sequencing the individual segments
