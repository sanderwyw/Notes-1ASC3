- PAT
	- Configure PAT to Use a Single IPv4 address
		- To configure PAT to use a single IPv4 address add the keyword *overload* to the *ip nat inside source* command
			- *ip nat inside source list (number) interface serial 0/1/0 overload*
	- Configure PAT to Use an Address Pool
		- An ISP may allocate more than one public IPv4 address to an organization
		- In this scenario the organization can configure PAT to use a pool of IPv4 public addresses for translation
		- To configure PAT for a dynamic NAT address pool, add the keyword *overload* to the *ip nat inside source* command
			- *ip nat inside source list 1 pool NAT-POOL2 overload*
	- Analyzing PAT
		- Server to PC
			- 1.
				- PC1 and PC2 send packets to Svr1 and Svr2
			- 2.
				- Packet from PC1 reaches R2 first
				- R2 modifies the source IPv4 address to 209.165.200.255 (inside global address)
				- R2 forwards the packet towards Svr1
			- 3. 
				- The packet from PC2 arrives at R2
				- PAT changes the source IPv4 address of PC2 to the inside global address of 209.165.200.225
				- PC2 has the same source port number as the translation for PC1
				- PAT increments the source port number until it is a unique value in its table
		- PC to server
			- 1.
				- PC1 and PC2 send packets to Svr1 and Svr2
			- 2.
				- Packets from PC1 reach R2 first
				- R2 modifies the source IPv4 address to 209.165.200.255 (inside global address)
				- Packet is forwarded towards Svr1
			- 3.
				- Packet from PC2 arrives at R2
				- PAT changes the source IPv4 address of PC2 to the inside global address 209.165.200.225
				- PC2 has the same source port number until it is a unique value in its table 
					- In this instance it is 1445
		- Server to PC
			- 1.
				- The servers use the source port from the received packets as the destination port 
				- The servers use the source address as the destination for the return traffic
			- 2. 
				- R2 changes the destination IPv4 address of the packet from Svr1 from 209.165.200.225 to 192.168.10.10 and forwards the packet toward PC1
			- 3.
				- R2 changes the destination address of packet from Svr2 from 209.165.200.255 to 192.168.10.11
				- R2 modifies the destination port back to its original value of 1444
				- Packet is forwarded toward PC2
