- IPv4 Address Structure
	- Determining the network address
		- A logical **AND boolean** operation is used in determining the **network address**. by comparing each digit of one address with the digit at the same place at the other address
			- 1 AND 1 = 1, 0 AND 1 = 0, 1 AND 0 = 0, 0 AND 0 = 0
			- Only if **both are 1** does the **network** address also have a **1 in that spot**
			- This essentially means that you just copy the IPv4 host address until the subnet mask is made up of 0s, from which point onwards you just always write 0
	- IP address types
		- Network address
			- All 0s
			- A message sent to this address will send said message directly to the center network host 
		- Host address
			- Combinations of 1s and 0s
		- Broadcast address
			- All 1s
			- A message sent to this address may be received by all hosts attached to that network
- Unicast, Broadcast and Multicast
	- Unicast
		- Sending a packet to one singular destination IP address
	- Broadcast
		- Sending a packet to all other destination IP addresses in the network
		- Destination has all 1s in the host portions
	- Multicast
		- Sending a packet to a multicast address group
		- For example: all hosts 10-19
- Types of IPv4 Addresses
	- Public
		- IPv4 addresses are globally routed between internet service provider (ISP) routers
	- Private
		- Most common blocks of addresses used by most organizations to assign IPv4 addresses to internal hosts
		- Not globally routable
	- NAT
		- Network Address Translation
		- Operates on a **router** or **edge** platform and connects private networks to public networks
		- An organization needs **one IP address** to represent an entire **group of devices** as they connect outside their network
		- Increases **security** by **hiding internal networks** from **public networks**
	- Special use
		- Loopback addresses
			- 127.0.0.0 /8
			- Commonly identified as just 127.0.0.1
			- Used on a host to test if TCP/IP is operational
		- Link-Local addresses
			- 169.254.0.0 /16
			- Used by windows DHCP clients to self-configure when no DHCP servers are available
