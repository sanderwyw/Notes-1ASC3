- Configuring Standard IPv4 ACLs
	- Numbered Standard IPv4 ACL Syntax
		- To create a numbered standard ACL, use the *access-list* command
			- *access-list (access-list-number) {deny | permit | remark (text)} source (source-wildcard) (log)*
			- Access-list-number
				- Number range is 1 to 99 or 1300 to 1999
			- Deny
				- Denies access if the condition is met
			- Permit
				- Permits access if the condition is matched
			- Remark (text)
				- (Optional) text entry for documentation
			- Source
				- Identifies the source network or host address to filter
			- Source-wildcard
				- (Optional) 32-bit wildcard mask that is applied to the source
			- Log
				- (Optional) Generates and sends an informational message when the ACE is matched
	- Named Standard IPv4 ACL Syntax
		- To create a named standard ACL, use the ip access-list standard command
			- ACL names are alphanumeric, case sensitive and must be unique
			- Capitalizing ACL names is not required but makes them stand out when viewing the running-config output
	- Applying a Standard IPv4 ACL
		- After a standard IPv4 ACL is configured, it must be linked to an interface or feature
			- Use *ip access-group* to bind a numbered or named standard IPv4 ACL to an interface
				- ip access-group {access-list-number | access-list-name} { in | out }
				- interface configuration
			- Use *no ip access-group* to remove an ACL from an interface
				- interface configuration
			- Use *show running-config* to review the ACL in the configuration
			- Use *show ip interface* to verify the ACL is applied to the interface
			- Use *show access-list*/ *show access-lists* to review the ACL in the configuration
			- Use *show ip interface* to verify the ACL is applied to the interface
- Modifying IPv4 ACLs
	- Text Editor Method
		- ACLs with multiple ACEs should be created in a text editor
		- This allows you to plan the required ACEs, create the ACL and then paste it into the router interface
		- Simplifies the tasks to edit and fix an ACL
		- To correct an error in ACL
			- Copy the ACL from the running config and paste it into text editor
			- Make the necessary edits or changes
			- Remove the previously configured ACL on the router
			- Copy and paste the edited ACL back to the router
	- Sequence Number Method
		- An ACL ACE can be deleted or added using the ACL sequence numbers
			- Use the *ip access-list standard* command to edit an ACL
			- Statements cannot be overwritten using an existing sequence number
				- The current statement must be deleted first with the *no 10* command
					- Afterwards, the correct ACE can be added using sequence number
- Secure VTY Ports with a Standard IPv4 ACL
	- A standard ACL can secure remote administrative access to a device using the vty lines by implementing the following two steps:
		- Create an ACL to identify which administrative hosts should be allowed remote access
		- Apply the ACL to incoming traffic on the vty lines
