- Cisco IOS Access and Save Config
	- Network Access Network
		- Console cable
			- A **physical** cable that can be used to access a device and provide maintenance by accessing the **terminal/ console**
		- Secure Shell
			- Establishes a *secure* remote **CLI (Command-Line-Interface)** connection to a device through a **virtual interface** over a network
		- Telnet
			- Establishes an *insecure* remote **CLI** connection to a device over a **network**. 
	- Configuration Files
		- startup-config
			- The saved configuration file that is stored in NVRAM. Contains all commands that will be used by the device upon startup or reboot. Does not lose contents when device if powered off.
		- running-config
			- Reflects the current RAM configuration. RAM is volatile memory and loses all its content when the device is powered off or is restarted.
		- To save changes made to the running configuration to the startup configuration file, use the **copy running-config** or **copy startup-config**
	- Altering Running Config
		- If you changed the running-config you can restore it to its previous configuration with the *reload* command.
		- If you saved the changes to the startup-config you may have to clear all configurations using *erase startup-config* command.
- Ports and Addresses
	- IP Addresses
		- IP addresses allow devices to locate each other and establishing end-to-end communication
		- IPv4
			- Uses *dotted decimal notation* and is represented by four decimal numbers between 0 and 255
			- An IPv4 subnet mask is a **32-bit** value that differentiates the *network* portion of the address from the *host* portion. Coupled with the IPv4 address, the subnet mask determines to which subnet the device is a member.
				- The network
				- **Routing Prefix** some IP-Addresses will end with a routing prefix such as /24. This indicates how many bits have been allocated for the network prefix and thus also how many are left for host addressing. /24 means there are 24 bits allocated for network prefix and 8 for host addressing. 
			- The *default gateway address* is the IP address of the **router**  that the host will use to access remote networks such as the internet
		- IPv6
			- Are **128 bits** long
			- Written as a string of **hexadecimal** values. Each hexadecimal value is made up of *4 bits*, meaning there are *16* different hexadecimal values (A to F and 0 - 9)
			- Divided into four strings of 4 hexadecimal values, each of which is four digits long
			- NOT case-sensitive
			- More recent than IPv4, is replacing most cases of IPv4

- Configuring IP addressing
	- IPv4 addresses can be entered **manually** or **automatically** using *DHCP*
		- DHCP gives devices connected to the server an IP address **automatically** so that they do not need to be assigned **manually** and **individually**
			- Configuring *DHCP* on windows
				- Control panel > Network Sharing Center > Change adapter settings (choose adapter) > select properties 
			- Benefits
				- End devices are typically **DHCP-enabled** by default
				- When changing network configuration, only a **central** adjustment has to be made
				- A device that is moved to another subnet is changed **automatically**
				- No link between **MAC address** and **IP-address**
				- More efficient
					- If there are 1000 mobile devices in department but there can only be 200 at a time, DHCP comes in handy
		- Changing *IPv4* address manually on Windows
			- Control panel > Network Sharing Center > Change adapter settings (choose adapter) > select properties
