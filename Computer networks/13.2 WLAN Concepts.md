	- Types of Wireless Networks
		- Wireless Personal-Area Network (WPAN)
			- Low power
			- Short range (20ft-30ft/ 6-9m)
			- Based on IEEE standard
			- 2.4 GHz frequency
			- Bluetooth
			- Zigbee
				- Link smarts devices
		- Wireless LAN (WLAN)
			- Medium range (300ft/ 90m)
			- Based on IEEE standard
			- 2.4 or 5.0 GHz frequency
		- Wireless WAN (WWAN)
			- Extensive geographic area
			- For national or global communication
			- Uses specific licensed frequencies
	- Wireless Technologies
		- Bluetooth
			- Used for device pairing at up to 300ft (100m)
			- IEEE WPAN standard
		- Bluetooth Low Energy (BLE)
			- Supports mesh topology to large scale network devices
		- Bluetooth Basic Rate/ Enhanced Rate (BR/EDR)
			- Supports point-to-point topologies and is optimized for audio streaming
		- Cellular Broadband
			- Carries both voice and data
			- Used by phones, laptops, tablets and cars
			- Global System of Mobile (GSM)
				- Internationally recognized
			- Code Division Multiple Access (CDMA)
				- Primarily in the US
		- Satellite Broadband
			- Uses directional satellite dish aligned with satellite in geostationary orbit
			- Needs clear line of site
			- Typically used in rural locations where cable and DSL are unavailable
	- Radio Frequencies
		- All wireless devices operate in the range of the electromagnetic spectrum
		- WLAN networks operate in the 2.4 and 5 GHz frequency bands
		- 2.4 GHz (UHF)
		- 5 GHz (SHF)

		- International Telecommunication Union (ITU)

		- Institute of Electrical and Electronics Engineers (IEEE)

			- Promotes the growth and acceptance of WLANs

- WLAN Operation
	- Frame Structure
		- The 802.11 frame format is similar to the Ethernet frame format, except that it contains more fields
		- Fields
			- Header
				- Frame Control
				- Duration
				- Address1
				- Address2
				- Address3
				- Sequence Control
				- Address4
			- Payload
			- FCS
	- CSMA/CA
		- WLANs are half-duplex and a client cannot "hear" while it is sending, making it impossible to detect a collision
		- WLANS instead use carrier sense multiple access with collision avoidance (CSMA/CA) to determine how and when to send data. A wireless client does the following
			- Listens to channel to see if it is idle
			- Sends a ready to send (RTS) message to the AP to request dedicated access to the network
			- Receives a clear to send (CTS) message from the AP granting access to send
				- Waits a random amount of time before restarting the process if no CTS message received
			- Transmits the data
			- Acknowledges all transmissions. If a wireless client does not receive an acknowledgment, it assumes a collision occurred and restarts the process

- Channel Management
	- Channel Selection
		- The 2.4 GHz band is subdivided into multiple channels each allotted 22 MHz and separated from the next channel by 5 MHz
		- A best practice for 902/11 WLANs requiring multiple APs is to use non-overlapping channels such as 1, 6 and 11
		- For the 5GHz standards 802.11, there are 24 channels
			- Each channel is separated from the next channel by 20 MHz
			- Non-overlapping channels are 36, 48 and 60

- WLAN Threats
	- Overview
		- A WLAN is open to anyone within range of an AP and the appropriate credentials to associate to it or to login
		- Attacks can be generated by outsiders, employees with bad intentions and even unintentionally by employees.
		- Wireless networks are specifically susceptible to several threats such as:
			- Interception of data
			- Wireless intruders
			- DoS attacks
			- Rogue APs
	- Rogue Access Points
		- A rogue AP is an AP or wireless router that has been connected to a network without authorization and against the active policy
		- The rogue AP can be used by an attacker to 
			- Capture MAC addresses
			- Capture data packets
			- Gain access to network resources
			- Launch a man-in-the-middle attack
		- A personal network hotspot could also be used as a rogue AP
			- For example, a user with secure network access enables their computer to become a Wi-Fi AP, potentially causing harm to those that connect to their Wi-Fi
		- To prevent the installation of rogue APs, organizations must configure Wireless Lan Controllers (WLCs) with rogue AP policies and use monitoring software to actively monitor the radio spectrum for unauthorized APs
	- Man-in-the-Middle Attack
		- The hacker sits within the data flow of two entities, and makes it so that they communicate with the hacker instead of eachother. The hacker can then read and modify the communication between the two entities without them knowing
		- Evil Twin Attack
			- An attacker introduces a rogue AP and configures it with the same Service Set Identifier (SSID)/ name as a legitimate AP
		- To overcome a MITM attack, all legitimate devices on a WLAN must be identified
			- After all of the legitimate devices are known, the network can be monitored for abnormal devices or traffic
- Securing WLANs
	- SSID Cloaking and MAC Address Filtering
		- These features keep wireless intruders out and protect data
		- SSID Cloaking
			- APs and some wireless routers allow the SSID beacon frame to be disabled
			- Wireless clients must be manually configured with the SSID to connect to the network
			- Hackers can't impersonate the SSID because everyone has to enter one specific SSID; no mistakes with connecting to the wrong network can be made
		- MAC Address Filtering
			- An administrator can manually permit or deny clients wireless access based on their physical MAC hardware address
			- A router would only permit a select few MAC addresses and reject all others, barring them from joining the WLAN
	- Original Authentication Methods
		- Authentication and encryption systems can be used to secure wireless networks
		- Two types of authentication were introduced with the original 802.11 standard
			- Open System Authentication
				- No password required
				- Typically used to provide free internet access in public areas like cafes, airports and hotels
				- Client is responsible for providing security as through a VPN
			- Shared Key Authentication
				- Provides mechanism such as WEP, WPA, WPA2 and WPA3 to authenticate and encrypt the data between a wireless client and AP
				- The password must be pre-shared between both parties to connect
				- Methods
					- Wired Equivalent Privacy (WEP)
						- The original 802.11 specification designed to secure the data using the Rivest Cipher 4 (RC4) encryption method with a static key
					- Wi-Fi Protected Access (WPA)
						- The Wi-Fi Alliance standard that uses WEP but secures the data within the much stronger Temporal Key Integrity protocol (TKIP) encryption algorithm. TKIP changes the key for each packet, making it much more difficult to hack
					- WPA2
						- Uses Advanced Encryption Standard (AES) for encryption
						- Considered the strongest encryption protocol
					- WPA3
						- Next gen Wi-Fi security. All WPA3-enabled devices use the latest security methods, disallow outdated legacy protocols and require the use of Protected Management Frames (PMF)
	- Authenticating a Home User
		- Home routers have two choices for authentication: WPA and WPA2. WPA has two authentication methods
			- Personal
				- Intended for home or small office networks
				- Users authenticate using pre-shared key (PSK)
				- Wireless clients authenticate with the wireless router using a pre-shared password
				- No special authentication server is required
			- Enterprise
				- Intended for enterprise networks
				- Requires a Remote Authenticate Dial-In User Service (RADIUS) authentication server
				- Device must be authenticated by the RADIUS server and then users must authenticate using 802.1X standard which uses the Extensible Authentication Protocol (EAP) for authentication
