- Static Routes (7)
	- Types of Static Routes
		- *Static routes* are **commonly** implemented on a network, **even** when there is a *dynamic routing protocol* configured
		- *Static routes* can be configured for *IPv4* and *IPv6*. They support the following **types** of static routes
			- Standard static route
			- Default static route
			- Floating static route
			- Summary static route
		- *Static routes* are configured using the **ip route** and **ipv6** route global configuration commands
	- Next-Hop Options
		- When configuring a *static route*, the **next hop** can be identified by an *IP address*, exit interface or both
		- **How** the destination is **specified**, **creates** one of the three following *types of static route*
		- Next-Hop Route
			- **Only** the *next-hop IP address* is specified
		- Directly connected static route
			- **Only** the *router exit interface* is specified
		- Fully specified static route
			- The *next-hop IP address* **and** *exit interface* are specified
	- IPv4 Static Route Command
		- IPv4 static routes are configured using the following global configuration command
			- Router(config)# ip route network-address subnet-mask { ip-address | exit-intf [ip-addres]} [distance]
	- IPv6 Static Route Command
		- IPv6 static routes are configured using the following global configuration command
			- Router(config)# ipv6 route ipv6-prefix/prefix-length {ipv6-address | exit-intf [ipv6-address]} [distance]

	- IPv4 Starting Routing Tables
		- Each router has entries only for **directly** connected networks and associated local addresses
	- IPv6 Starting Routing Tables
		- Each router has entries only for **directly** connected networks and associated local addresses
- Configure IP Static Routes (8)
	- IPv4 Next-Hop Static Route
		- In a *next-hop static route*, only the *next-hop IP address* is specified
		- **Exit interface** is derived from the *next hop*
		- Command example
			- R1 (config) # ip route 172.16.1.0 255.255.255.0 172.16.2.2
	- IPv6 Next-Hop Static Route
		- The commands to configure R1 with the *IPv6* static routes to the a remote network are as follows
			- R1 (config) # ipv6 unicast-routing
			- R1 (config) # ipv6 route 2001:db8:acad:1::/64 2001:db8:acad:2::2
	- IPv4 Directly Connected Static Route
		- Another option is to use the **exit interface** to specify the *next-hop* address
			- R1 (config)#  ip route 172.16.1.0 255.255.255.0 s0/1/0
	- IPv6 Directly Connected Static Route
		- Using next-hop address is recommended
			- R1(config)# ipv6 route 2001:db8:acad:1::/64  s0/1/0
	- IPv4 Fully Specified Static Route
		- Both *exist interface* and *next-hop IP address* are specified
		- This is used when the exit interface is a **multi-access interface**
		- When the *exit interface* is an Ethernet network, the static route should include a *next-hop address*. You can also use a *fully specified static route* 
	- IPv6 Fully Specified Static Route
		- If the IPv6 static route uses an *IPv6 link-local address* as the *next-hop address*, use a *fully specified static route*
			- Because *IPv6 link-local addresses* are **not** contained in the *IPv6 routing table*
	- Verify a Static Route
		- Useful commands
			- show ip route
			- show ipv6 route
			- ping
			- traceroute
			- show ip route static
			- show ip route network
			- show ip running-config | section ip route
		- You can replace *ip* with *ipv6* for the IPv6 versions of the command
- Configure IP Default Static Routes (5)
	- Default Static Route
		- A *default route* is a *static route* that matches **all** packets
		- A *single default route* represents **all** networks **not** in the *routing table*
		- Routers often use *default routes* that are either **configured locally** or **learned from another router**
		- Default route = Gateway of Last Resort
		- *Default static routes* are commonly used when **connecting an edge router** to a *service provider network* or with a *stub router*
		- IPv4 Default Static Route
			- network address 0.0.0.0 and subnet mask 0.0.0.0
			- Router(config)# ip route 0.0.0.0 0.0.0.0 {ip-address | exit-intf}
		- IPv6 Default Static Route
			- Command syntax for an IPv6 default static route is similar to any other IPv6 static route, except that the ipv6-prefix/prefix-length is ::/0, which matches all routes
			- Router(config)# ipv6 route ::/0 {ipv6-address | exit-intf}
	- Configure a Default Static Route
		- IPv4
			- R1(config)# ip route 0.0.0.0 0.0.0.0 172.16.2.2
		- IPv6
			- R1(config)# ipv6 route ::/0 2001:db8:acad:2::2
	- Verify a Default Static Route
		- show ip route static
			- The * next to a route means that it is given the role of Gateway of Last Resort
		- show ipv6 route static
- Configure Floating Static Routes (3)
	- Floating Static Routes
		- Type of *static route*
		- Used to provide a backout (alternative) path to a primary static or dynamic route
		- Only used when *primary route* is **not** available
		- *Floating static route* is configured with a **higher administrative distance** than the *primary route*
			- Administrative distance represents the trustworthiness of a route
			- If multiple paths exist, the router will choose the path with the **lowest** administrative distance
		- *Static routes* have a admin distance of 1 which makes them preferable to routes learned from dynamic routing protocols
	- Configure IPv4 and IPv6 Floating Static Routes
		- Normal
			- R1(config)# ip route 0.0.0.0 0.0.0.0 172.16.2.2
		- Floating Static
			- R1(config)# ip route 0.0.0.0 0.0.0.0 172.16.2.2 5
- Configure Static Host Routes (6)
	- Host Routes
		- *IPv4* address with a 32-bit mask, or an IPv6 address with a 128-bit mask
		- Three ways a host route can be added to the routing table
			- **Automatically** installed when an IP address is configured on the router
			- **Configured** as a static host route
			- Host route **automatically** obtained through other methods (discussed in later courses)
	- Automatically Installed Host Routes
		- Cisco IOS *automatically* installs a host route also known as a *local host route* when an *interface address* is configured on the router
		- This is in additional to the connected route (designated with C in routing table)
		- The local routes are marked with L
	- Static Host Routes
		- A host route can be a **manually configured** *static route* to direct traffic to a specific destination device
			- They use a full IP address (/32 for IPv4 or /128 for IPv6)
