Network components
- Various Terminology
	- Bandwidth
		- Measure of how much information a network can transfer in a given amount of time
	- Data Packet
		- Fundamental units of communication for devices connected on a network
		- Contains a *Header*, *Payload* and *Trailer*
			- A **header** contains information that allows for transmittion of the data packet
				- IP address of sender and receiver
				- IP version (IPv4 or IPv6) of sender and receiver
				- Type of data packet
				- Size of data packet in bytes
				- 16-bit identification number 
					- so destination computer can identify and reassemble the payload from the data packet
				- Checksum
					- checks for errors by calculating all bytes in the packet to ensure each one is present. Packet will be resent otherwise
			- The **payload** is the data which we want to be transferred (such as a video, a photo, an email)
				- Makes up the bulk of the packet
				- Routers do not read it
				- If it has a fixed length such as the 32 bits of IPv4 address it inserts extra zeros to meet the length requirement
			- The **trailer** signals the end of a packet
				- Not always included
				- May include additional error checking, such as cyclical redundancy
					- CRC: adds up all ones in payload and storing that value in *trailer*. Each receiving device repeats proces and gives error when the number changes
- Host Roles
	- A **computer** on a network is a *host* or end device. 
		- May also be called IP host as they each have their own **IP address**
		- Where a package originates from or where it is received
		- Data originates from an *end device*, flows through the network and then arrives at another *end device*
	- A **server** is a number of *computers (hosts)* that provide/ share information to other *hosts*
		- email servers
		- web servers
		- file servers
	- A **client** is a computer that sends a request to the **server** in order to retrieve information
		- web page from a web server
		- email from an email server
- Network Hardware
	- Modem
		- Brings internet service to the router
	- Intermediary network devices 
		- An intermediary device that interconnects *end devices*
			- **switches**
				- Connects plugged-in devices by receiving their data packets, determining their correct address and then transmitting them to that correct address
				- Most commonly used for *ethernet*
				- uses *MAC addresses* to forward data on *layer 2*
				- **Multilayer** switches can forward data on *layer 3*/ the network layer
			- **wireless access points**
			- **routers**
				- A **computer** that forwards data packets between computer networks (such as the internet or another server)
				- When a router receives a data packet, it reads the *network address information* in the *packet header* to determine its destination. It then uses information in its *routing table* to direct the packet to the next network in its journey
				- A data packet is forwarded from one router to another through an internetwork until it reaches its destination node
			- **firewalls**
				- Protects resources of a network or computer from outside abuse
				- Monitors incoming and outcoming traffic and blocks and allows specific traffic based on security rules
		- Manage data as it flows through the network
			- Regenerate and retransmit (lost) data signals
			- Record and maintain information about what pathways exist in the network
			- Notify other devices or errors and communication failures
	- Network medium
		- Communication across a *network* is carried through a *medium* which allows a package to travel from *source* to *destination* (like roads on which cargo is carried)
		- Some mediums have intrinsic advantages over others in certain scenarios
			- **metal wires within cables**
				- uses electrical impulses
				- copper
				- cheaper
			- **fiber-optic cables**
				- uses pulses of light which can be read as data
				- expensive
				- extremely fast
			- **wireless transmission**
				- uses modulation of specific frequencies of *electromagnetic* waves
- Types of networks
	- Network infrastructures vary greatly in terms of
		- Size of area covered
		- Number of users connected
		- Number and types of services available
		- Area of responsibility
	- A **central server** is a computer with the sole purpose of handling data transfers for many computers in the same network.
		- This is necessary as a network of many computers can become very slow if there isn't one computer handling everything
	- A **Peer-to-Peer** server is a network where computers directly share networks without a central server computer.
		- Used for very small networks as it can be slow for bigger networks
		- Computers are both clients and servers
		- Advantages:
			- Easy to set up
			- Less complex
			- Lower cost
			- Used for simple tasks
				- Such as transferring files and sharing printers
		- Disadvantages
			- No centralized administration
			- Not as secure
			- Not scalable
			- Slow performance
	- **LAN** or Local Area Network
		- Network infrastructure that spans a *small geographical area*
		- Administered by a *single* organization or individual
		- Provide *high-speed bandwidth* to internal devices
		- Such as home network!
	- **WAN** or Wide Area Network
		- Network infrastructure that *interconnects multiple LANs* over *wide* geographical areas
		- Administered by *one or more* service providers
		- Provides *slower speed* between
		- May use *copper wires*, *fiber optic cables* and *wireless transmissions*
	- The **Internet**
		- A *worldwide collection* of interconnected LANs and WANs
		- Not owned by any individual or group
		- Several groups were developed to maintain structure on the internet:
			- IETF (Internet Engineering Task Force)
			- ICANN (Internet Corporation for Assigned Names and Numbers)
			- IAB (Internet Architecture Board)
- Internet Connections
	- Users can be connected to the internet in a variety of ways depending on requirements and details
	- Requirements
		- **Home users** and **small offices** don't need extremely fast hardware and often use *broadband cable*, *broadband digital subscriber line (DSL)*, *wireless WAN's*, and *mobile services*
		- **Organizations** need faster connections for *IP phones*, video conferencing and data center storage
		- **Business-class** interconnections are provided by *service providers* such as:
			- Business DSL
			- Leased lines
			- Metro Ethernet
	- Connection types
		- Cable
			- High bandwidth
			- Physical
			- Always on
			- Used by cable television service providers
		- DSL
			- High bandwidth
			- Physical
			- Always on
			- Internet connection that runs over a telephone line
		- Cellular
			- Uses a cell phone network to connect to the internet
			- Non-physical
		- Satellite
			- Sends signal to a satellite in space which then broadcasts that signal so it can be picked up by certain devices
			- Major benefit to rural areas without Internet Service Providers
		- Dial-up telephone
			- Inexpensive, low bandwidth option using a modem
			- Essentially just creates a one-way connection to one internet service provider
		- Ethernet
			- *Cable* that allows computers in a *LAN* to communicate with each other
			- Very widespread
	- Converging Networks
		- Can deliver data, voice and video over the same network infrastructure.
