- IP (Internet Protocol)
	- IPv4
		- 32-bits
		- Represented by four decimal numbers between 0 and 255
		- Subnet mask
			- Helps the IPv4 address differentiate between the **network** and **host** portions of the address
			- Determines to which subnet the device is a member
		- Routing prefix
			- Written at end of IP-address such as /24
			- Indicates how many bits have been allocated for the network and how many for host
			- /24 => 24 bits for network prefix, 8 bits for host addressing
	- IPv6

- LAN
	- Network infrastructure that spans a **small geographical area**
	- Administered by **one** organization
- WAN
	- Network infrastructure that spans a **large geographical area**
	- Administered by **multiple** service providers
- Central server
	- Network with computer that handles all data transfers for hosts in the same network as it
- Peer-to-Peer server
	- Hosts share packets without a central server
	- Often used for small, less complex networks
- Connection types
	- Cable
		- High bandwidth
		- Always on
		- Used by cable television
	- DSL
		- High bandwidth
		- Physical
		- Internet runs over telephone lines
	- Cellular
		- Uses cell phone network to connect to internet
	- Satellite
		- Sends signal to a satellite in space which then broadcasts that signal so it can be picked up by certain devices
	- Dial-up telephone
		- Inexpensive, low bandwidth option using a modem
		- Creates one-way connection to one internet provider
	- Ethernet
		- Cable that allows computers in a **LAN** to communicate with eachotoher
